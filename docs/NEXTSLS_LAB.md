# NextSLS V5 联调中心

Render 管理端：`/tms/admin/nextsls-lab`。管理员、CSRF、站点紧急开关与单票授权规则保持原样。

先在代理管理使用 V5 快速接入，输入名称、nextsls.com 租户 HTTPS 根域和 App Token。系统读取该租户文档及 get_services；文档指纹和测试字样只是线索，get_services 也只证明读取能力。没有任何步骤将文档、渠道名称或只读认证当作生产创建许可。

- **A：预检。** 选择现有账号、读取渠道，上传带测试标记的 XLSX。使用现有渠道规则预检，解析原图、生成装箱单供校验；不发布附件，不创建订单，不调用供应商写入。同一账号的认证、渠道、规则和本站开关问题分别显示。建单时才通过现有签名文件流程发布附件。
- **B：受控实测。** 有官方测试账号，或现有合同、平台条款、账号许可等明确允许时，登记一份有版本或记录编号的联调依据。确认非履约、不揽收，免计费或实际费用已经另行获准。录入依据覆盖的账号与渠道（每项 `代理ID:渠道代码`，一次最多 1,000 项）。不存在证据时不提交；不要求凭空增加新的书面证明，仅核实已有依据是否覆盖。
- 从联调中心登记已标记样本；保留原始文件、测试标记及独立客户归属。样本进入单票审核，不纳入正常业务批次。站点许可及单票授权齐备后，由管理员从订单页明确点击一次正式提交；继续使用统一 send_order、带 XR-LAB- 标记的唯一客户参考号、真实单号回写和严格查询。
- 依据自动到期或可撤销，只影响联调单；域名、Token、渠道或原文件更换使原绑定失效。历史验收副本仍不可提交；结果未知先对账，联调单不可解除重试锁。已有旧版环境变量许可继续服务原来不属于联调中心的样本，联调中心不依赖它。
- 实际发送后，只记可展示的回执字段（HTTP、V5 状态、单号和脱敏错误）及同账号查询核对结果。不要把文件签名、Token 和原始敏感响应写进依据、审计或报告。

当前版本不猜测或自动发现未公布的沙箱地址；官方测试账号必须符合现有 V5 租户域名约束。新增不兼容域名或显式测试协议时，先以官方依据审查通用适配，不能把生产接口切换成猜测地址。
